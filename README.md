# Practicando

Practice Spanish verb conjugations with endless, customizable flashcards. Pick the verbs
(top 10–500 by frequency), tenses, moods and pronouns; get instant feedback; track progress
on the History and Metrics tabs. An installable PWA (Next.js + Supabase).

## Develop

```bash
npm install
npm run db:setup     # once: Supabase schemas + .env.local (see docs/deploy.md)
npm run dev          # http://localhost:3000 — uses the practicando_dev schema
npm test             # data tests
```

Verb data is static JSON in `public/data/`, generated by `tools/conjugator` (`npm run
conjugations`). Deploys, environments and limits: [docs/deploy.md](docs/deploy.md).

`spike-mobile/` is the earlier mobile/voice spike (reference only; see `PWA_SCOPING.md`).
