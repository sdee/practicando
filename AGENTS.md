# Practicando

- Next.js 16 App Router PWA, Supabase (Listo's shared project, schema per environment).
  Read the relevant guide in `node_modules/next/dist/docs/` before using Next APIs.
- Verb data is committed JSON (`public/data`), generated by `tools/conjugator` — never
  conjugate at runtime. Fix wrong forms in `CORRECTIONS`, run `npm run conjugations`.
- Dev vs prod = `src/lib/supabase.ts` `SCHEMA` (derived from the build env) + `src/config/environments.ts`.
  Don't add per-env config for the database. See `docs/deploy.md`.
